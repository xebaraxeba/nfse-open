# Código de conduta

Queremos que o nfse-open seja um espaço acolhedor para qualquer pessoa, de MEIs a contadores e devs, independentemente de experiência, identidade ou origem.

## O que esperamos

- Respeito e gentileza, inclusive ao discordar.
- Críticas construtivas, voltadas ao trabalho e não à pessoa.
- Paciência com quem está começando.
- Cuidado com dados alheios: nunca exponha documentos ou informações fiscais de terceiros.

## O que não aceitamos

- Assédio, insultos, ataques pessoais ou linguagem discriminatória.
- Publicar informações privadas de alguém sem permissão.
- Qualquer conduta que seria inadequada num ambiente profissional.

## Aplicação

Mantenedores podem remover comentários, commits ou contribuições que violem este código e, em casos graves ou repetidos, bloquear participantes.

Para relatar um problema, abra uma issue marcada como confidencial ou entre em contato com os mantenedores pelo perfil do GitHub. Todo relato é tratado com sigilo.

Este código se inspira no [Contributor Covenant](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).
