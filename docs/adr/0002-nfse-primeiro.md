# ADR 0002: Começar pela NFS-e nacional

- Status: Aceito
- Data: 2026-11-24

## Contexto

NF-e (produtos) e NFS-e (serviços) são bem diferentes. A NF-e tem regras por estado e muitos campos de ICMS; a NFS-e nacional usa uma API única.

## Decisão

O primeiro escopo é só a NFS-e nacional. A NF-e entra depois como novo módulo.

## Consequências

- Entrega mais rápida, focada em MEIs e prestadores de serviço.
- Usuários que emitem NF-e ainda não são atendidos na primeira versão.
